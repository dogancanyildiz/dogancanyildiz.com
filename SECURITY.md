# Güvenlik politikası

Bu depo kişisel sitemin, dogancanyildiz.com'un, kaynağını tutar. Sitede veya
bu kodda bir açık bulursan duymak isterim.

## Bildirim

- E-posta: me@dogancanyildiz.com
- Veya GitHub üzerinden özel rapor: Security sekmesi, "Report a
  vulnerability" (özel açık bildirimi açık).

Güvenlik sorunları için genel issue açma.

Ne bulduğunu, nasıl yeniden üretildiğini ve varsa önerilen düzeltmeyi yaz.
Bildirimleri 72 saat içinde onaylamayı, doğrulanan sorunları 14 gün içinde
kapatmayı hedefliyorum. Ödül yok; istersen changelog'da kredi verilir.

## Kapsam

- Bu depodaki uygulama kodu.
- https://dogancanyildiz.com üzerindeki canlı site (lütfen yıkıcı olmayan
  test: hizmet reddi yok, iletişim uç noktasında bir avuçtan fazla otomatik
  tarama yok).

Kapsam dışı: sitenin dayandığı harici servisler (Cloudflare, GitHub, posta
sunucusu); onları ilgili tedarikçiye veya sahibine bildir.
